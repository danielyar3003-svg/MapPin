# MapPin

Бесплатный редактор карт для серверов **SA-MP** и **open.mp**.
Работает как программа для Windows (Electron) и в браузере.

Программа не содержит файлов игры: модели, текстуры и карта читаются из вашей установленной GTA San Andreas.

## Что умеет (этап 1)

- Загружает карту San Andreas из папки игры: `gta.dat`, IDE, текстовые и бинарные IPL, архивы `gta3.img` / `gta_int.img`, модели DFF, текстуры TXD (DXT1/3/5, палитры, несжатые).
- Подгружает город вокруг камеры с учётом дистанций прорисовки и LOD.
- Подхватывает объекты SA-MP 18631+ из `SAMP/SAMP.img` и `SAMP/SAMP.ide`, если клиент установлен.
- Браузер моделей с поиском по ID и имени.
- Расстановка, перемещение и поворот объектов гизмо, групповое редактирование, шаг привязки.
- Свойства объекта: модель, позиция, поворот, мир, интерьер, дистанция, заметка.
- Отмена и повтор, копирование, дублирование.
- Пипетка (клик по зданию карты) и копирование здания карты в проект (Alt+клик).
- Экспорт в `CreateDynamicObject` (Streamer) или `CreateObject`.
- Импорт из Pawn-кода (`CreateObject`, `CreateDynamicObject`, `CreateDynamicObjectEx`, `CreatePlayerObject`).
- Проекты в файле `.mappin.json` и автосохранение.

## Управление

| Клавиши | Действие |
|---|---|
| ПКМ + мышь | осмотреться |
| ПКМ + W A S D, Q/E | полёт, вниз/вверх |
| Shift | быстрее |
| ПКМ + колесо | скорость полёта |
| ЛКМ | выбрать (Shift/Ctrl — несколько) |
| G / R / L | перемещение / поворот / локальные оси |
| F | показать выбранное |
| Ctrl+D, Ctrl+C/V, Delete | дублировать, копировать/вставить, удалить |
| Ctrl+Z / Ctrl+Y | отменить / повторить |
| Ctrl+S / Ctrl+O | сохранить / открыть проект |
| F1 | справка |

## Запуск из исходников

Нужен Node.js 20+.

```bash
npm install
npm start          # программа (Electron)
npm run dev:web    # браузерная версия на http://localhost:5173
npm test           # тесты
npm run dist       # установщик для Windows в папке release/
```

В браузере папка игры выбирается через диалог «выбрать папку» (Chrome, Edge, Firefox).

## Устройство

```
src/formats/   разбор форматов GTA SA: IMG, IDE, IPL, DAT, RenderWare DFF/TXD, DXT
src/game/      доступ к папке игры, загрузка данных, сборка 3D-моделей
src/editor/    документ и история, сцена, камера, потоковая отрисовка карты
src/export/    Pawn: экспорт/импорт, углы SA-MP
src/ui/        интерфейс
electron/      оболочка Windows-программы (чтение файлов, диалоги)
tests/         тесты на синтетических файлах игры
```

Порядок углов поворота SA-MP задан в одном месте — `src/export/rotation.ts` (`SAMP_EULER_ORDER`).
